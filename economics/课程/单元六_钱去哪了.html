银行是什么？你的钱去了哪里？

核心概念：银行、存款、贷款
家长提示：很多孩子以为钱存进银行就是"锁在保险箱里"。这节课的关键是让孩子理解银行是怎么"转动"钱的——吸收存款、发放贷款，让钱流动起来创造价值。
🤔 开场提问（3分钟）
  • "你把钱存进银行之后，钱去哪了？是不是就放在那里不动了？"
  • "银行凭什么给你利息？它又不是慈善机构，它赚什么？"
  • "为什么银行的大楼总是特别漂亮、特别高？"
📖 情景故事（5-8分钟）

《小村里的大金库》

在一个村子里，大家赚到钱就藏在家里。但问题是：

  • 农民老张想开面包店，但没有启动资金买烤箱
  • 教师小李存了很多钱，但放在家里又怕丢，也没有增加
  • 铁匠老王需要借钱买材料，但不知道找谁借

有一天，一个聪明人小赵说："我来建一个'大金库'！"

  • 他把村民的闲钱收集起来，保证安全，还付一点利息作为感谢
  • 他把这些钱借给需要钱开店、买材料的人，收一点贷款利息
  • 贷款利息 > 存款利息，中间的差额就是小赵的利润

结果：

  • 存钱的人——钱安全了，还有利息赚 ✅
  • 借钱的人——有钱做生意了 ✅
  • 小赵——赚到了差价 ✅
  • 村子——面包店开业了，大家都买到了面包 ✅

小赵的"大金库"，就是银行。

💡 概念讲解（5-8分钟）

银行是做什么的？

银行是一个"钱的搬运工"——把钱从暂时不用的人手里，搬到需要用钱的人手里。

银行的三门生意：

业务做什么举例
吸收存款帮你保管钱，还付你利息你存1000元，一年后变成1020元
发放贷款把钱借给需要的人，收更高利息借给企业100万，一年后收回105万
中间服务转账、汇款、换外汇等跨行转账手续费

银行怎么赚钱？

  • 贷款利率（5%）> 存款利率（2%）→ 差额（3%）就是银行的收入
  • 你存1000元，银行给你20元利息
  • 银行把你的1000元借给企业，收50元利息
  • 银行赚了30元

那银行能把所有存款都借出去吗？

不能！因为你随时可能来取钱。所以银行必须留一部分钱备用（叫"准备金"）。

如果所有人都同时来取钱——银行的钱不够——这就叫"挤兑"，银行会倒闭！所以存钱要选安全的银行。

除了银行还有哪些金融机构？

  • 证券公司——帮你买卖股票
  • 保险公司——帮你管理风险（还记得第13课吗？）
  • 基金公司——帮很多人一起投资，分散风险
💬 亲子讨论（5分钟）

讨论1：如果你有1000元，你会放在家里还是存银行？为什么？

讨论2：为什么借钱要付利息？如果不收利息会怎样？

利息是"借用别人钱的代价"。如果不收利息，谁都可以随便借钱不还的风险就大了。利息也补偿了出借人"这段时间不能用这笔钱"的损失（还记得机会成本吗？）。

讨论3：你觉得以后还会有银行大楼吗？还是全变成手机上的App了？

🎯 动手挑战（5分钟）

挑战：开一家"迷你银行"

假设你开了一家银行，有以下客户：

  • 小红存了500元（你承诺给3%年利息）
  • 小刚存了300元（你承诺给3%年利息）
  • 老王来借600元开店（你收8%年利息）

算一算：

  1. 你一年要付多少存款利息？（500+300）× 3% = ？
  2. 你一年收多少贷款利息？600 × 8% = ？
  3. 你一年赚了多少？
  4. 你还剩多少"准备金"（没借出去的钱）？够不够应对小红和小刚同时来取钱？
⭐ 一句话带走

"银行不只是存钱的地方，它是'钱的搬运工'——
把闲置的钱搬到需要的地方去，让钱流动起来创造价值。"

钱为什么不值钱了？

核心概念：通货膨胀
家长提示：用孩子能感受到的价格变化来讲通胀最有效——问问他们小时候（或爸爸妈妈小时候）东西多少钱，现在多少钱。这节课也解释了为什么"把钱全部藏在家里"不是好主意。
🤔 开场提问（3分钟）
  • "你知道爸爸/妈妈小时候一根冰棍多少钱吗？现在呢？"
  • "为什么以前5毛钱能买到的东西，现在要5块钱？"
  • "是不是所有东西都在涨价？有没有降价的东西？"
📖 情景故事（5-8分钟）

《时间旅行者小杰》

小杰有一个超能力：穿越时空。

他拿着100块钱，先穿越到了1990年：

  • 一碗牛肉面：2元 → 100块能吃50碗！
  • 一支铅笔：0.1元 → 100块能买1000支！
  • 一台电视：2000元 → 买不起……

然后他穿越到了2025年（现在）：

  • 一碗牛肉面：20元 → 100块只能吃5碗
  • 一支铅笔：2元 → 100块只能买50支
  • 一台电视：3000元 → 还是买不起……但现在的电视比1990年的好100倍

小杰发现：同样是100块，能买到的东西越来越少了。

钱还是那个钱，但它的"购买力"下降了。

这就是——通货膨胀。

💡 概念讲解（5-8分钟）

什么是通货膨胀？

通货膨胀 = 钱越来越多，导致钱的"购买力"下降，物价普遍上涨

为什么会发生通胀？

想象一个比喻：

一个教室里有20个同学和10个苹果。每个苹果"值"2个同学的购买力。

如果突然给每个同学发了10倍的钱——每个人都很"有钱"了。

但苹果还是只有10个！大家争着买，苹果就涨价了。

钱多了，但东西没变多 → 钱就不值钱了。

通胀的原因：

原因解释例子
钱印太多货币供应量增加太快津巴布韦曾印了100万亿面值的钞票
需求增加大家都想买，东西就那么多疫情后大家都想旅游，机票涨价
成本上升原材料涨价，产品跟着涨石油涨价 → 运费涨 → 所有东西都涨

通胀是坏事吗？

温和的通胀（每年2-3%）其实是正常的、甚至是好事：

  • 如果物价一直不变或下降 → 人们会等"更便宜"再买 → 经济停滞
  • 温和通胀鼓励人们消费和投资 → 经济活跃

但恶性通胀（每年几十甚至几百%）就是灾难：

  • 今天的钱明天就不值钱了 → 大家赶紧花掉 → 更通胀
  • 存了一辈子的钱突然变成废纸

怎么应对通胀？

  • 不要把所有钱藏在家里（越放越不值钱）
  • 存银行、买理财、投资——让钱增长的速度超过通胀
  • 学习技能、提升自己——能力不会贬值
💬 亲子讨论（5分钟）

讨论1：你注意到什么东西涨价了？什么东西反而变便宜了？

电子产品（手机、电脑）随着技术进步反而越来越便宜、性能越来越好。而人工服务（理发、家政）一直涨价。有些东西如房子、教育、医疗涨得特别快。

讨论2：如果通胀让钱越来越不值钱，那为什么要存钱呢？

讨论3：你听过大人抱怨"物价涨了工资没涨"吗？这就是通胀对普通人的影响。

⭐ 一句话带走

让钱'工作'起来，跑赢通胀，才能保住你的财富。"

全世界在做生意

核心概念：国际贸易、汇率
家长提示：这节课让孩子理解"全球化"。看看孩子身边有多少东西是外国来的，有多少中国制造的东西在外国卖。可以拿出几件物品看"Made in"标签。
🤔 开场提问（3分钟）

让孩子拿起身边几样东西看看标签，然后问：

  • "你的鞋子/文具/衣服，是在哪个国家生产的？"
  • "为什么我们用的东西来自全世界各地？"
  • "如果把中国和外国的贸易全断了，生活会怎样？"
📖 情景故事（5-8分钟）

《一支铅笔的环球之旅》

你手里有一支普通的铅笔。看起来很简单，对吧？

但这支铅笔的"身世"比你想象的复杂得多：

  • 🌲 木材可能来自南美洲的雨林
  • 🖊️ 石墨笔芯的原料可能来自中国的矿山
  • 🟡 黄色油漆的颜料可能来自印度的化工厂
  • ⚙️ 金属箍的矿石可能来自澳大利亚
  • 🇸🇱 橡皮擦的橡胶可能来自东南亚的种植园

所有这些材料从世界各地运到一个工厂，组装成一支铅笔，再运到你附近的商店。

一支几毛钱的铅笔，背后是全球几十个国家、成千上万人的合作。

如果每个国家都只用自己的资源做铅笔——木材少的国家的铅笔会又贵又差。

这就是为什么需要国际贸易。

💡 概念讲解（5-8分钟）

什么是国际贸易？

国际贸易 = 国家和国家之间互相买卖商品和服务

为什么需要国际贸易？

  • 资源不同——中东有石油、巴西有咖啡、中国有稀土
  • 擅长不同——日本擅长汽车、美国擅长芯片、法国擅长奢侈品
  • 成本不同——同样一件衣服，在中国生产比在美国便宜得多

还记得第6课的"比较优势"吗？每个国家做自己最擅长的事，然后交换，大家都受益。

但国际贸易有个问题：各国的钱不一样！

中国用人民币（¥），美国用美元（$），日本用日元（¥），欧洲用欧元（€）。

一个中国人想买美国手机，拿人民币人家不收啊！

所以需要汇率——一种货币换成另一种货币的"价格"。

货币大概汇率意思
1美元≈ 7.2人民币拿7.2元人民币能换1美元
1欧元≈ 7.8人民币拿7.8元人民币能换1欧元
100日元≈ 4.8人民币拿4.8元人民币能换100日元

汇率会变：

  • 人民币升值 → 出国旅游便宜了，但出口商品变贵了（外国人不买了）
  • 人民币贬值 → 出口商品便宜了（外国人买得多），但进口东西贵了

中国在国际贸易中的角色：

  • "世界工厂"——全球很多产品在中国制造
  • 出口大国——卖给全世界手机、服装、家电
  • 进口大国——也从全世界买石油、芯片、粮食
💬 亲子讨论（5分钟）

讨论1："买国货好"还是"买全世界的好"？

没有绝对答案。国际贸易让大家都能买到性价比最高的东西。但某些关键领域（如芯片、粮食）如果完全依赖外国，有被"卡脖子"的风险。所以需要在开放和自主之间找平衡。

讨论2：如果你去日本旅游，一瓶水100日元，贵吗？

讨论3：你觉得未来国际贸易会越来越多还是越来越少？为什么？
